Заказ отдельной позиции

Работа начинается с даты прихода: остатки будут пересчитаны на этот день.
Проект сохраняется только по кнопке «Заказан» — брошенный черновик удаляется сам.

Загружаю заказы...
Назовите заказ именем производства или человека, которому отдаёте заказ, — или придумайте оригинальное название. Можно оставить пустым: после «Заказан» подставится позиция.

Выбери товар — посчитаю распределение по размерам
Как считается. Всё — по методике оборачиваемости: скорость каждого размера — это его продажи за выбранный сезон, делённые на дни, когда размер реально был в наличии (размер, кончившийся в середине окна, не выглядит «менее ходовым»). Остатки прогнозируются на дату прихода проекта по этим темпам. «С учётом остатков» — заказ закрывает дыры по размерам; «чистая пропорция» — делит ровно по долям темпов. Колонка «Заказ» открыта для ручной правки — производству часто нужны круглые числа. Кнопка «Заказан» сохраняет проект и добавляет сумму в графу «Заказано» на странице Остатков; несохранённый проект удаляется при выходе.
